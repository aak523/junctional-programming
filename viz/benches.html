The state, object by object

Every piece of state in world.py, each drawn as the thing it actually is. The panes are the real benches, running — pick a state to restage one, click into a pane to orbit it, or open it full size. The map is docs/STATE.md; the globe that assembles them is here.

Each object is a module (<name>3d.js) that takes the real state fields and nothing else, plus a bench page with no chrome — state, theme and spin are URL parameters. The states are the component's real range, including the ones that cost money: a starved queue, a stranded site, a contract whose tail is all obligation, a pool of options about to expire worthless. Panes mount as they scroll into view and are released when they leave, so only a few hold a drawing context at once.
